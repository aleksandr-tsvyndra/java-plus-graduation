# Explore With Me

## 📋 О проекте
Микросервисное приложение Explore With Me позволяет пользователям делиться информацией об интересных событиях и находить компанию для участия в них. 

## 🏗️ Архитектура
Бэкенд приложения разбит на три основных модуля: **core**, **infra** и **stats**, каждый из которых 
в свою очередь состоит из подмодулей.

### Модуль infra
Данный модуль является инфраструктурным: он отвечает за конфигурирование и 
взаимодействие микросервисов. Его структура:

1. **Config Server** - централизованный сервис конфигурации
2. **Discovery Server (Eureka)** - сервис регистрации и обнаружения
3. **Gateway Server** - API Gateway для маршрутизации запросов

### Модуль stats
Модуль stats отвечает за хранение количества обращений пользователей к спискам 
событий и количестве запросов к подробной информации о событии, что позволяет делать 
различные выборки для анализа работы основного приложения. У 
него следующая структура:

1. **stats-client** - клиент (API) сервиса статистики
2. **stats-dto** - хранилище, в котором размещены объекты взаимодействия сервиса и клиента
3. **stats-server** - основная логика сервиса статистики с БД

### Модуль core
Core хранит в себе основную бизнес-логику приложения, которая разбита на шесть 
отдельных веб-приложений на базе Spring Boot, а также модуль общих DTO. 
Структура:

1. **category-service** - сервис, отвечающий за работу с категориями
2. **compilation-service** - сервис, отвечающий за работу с подборками
3. **event-service** - сервис, отвечающий за работу с мероприятиями
4. **request-service** - сервис, отвечающий за работу с запросами на участие в мероприятии
5. **review-service** - сервис, отвечающий за работу с отзывами
6. **user-service** - сервис, отвечающий за работу с пользователями
7. **interaction-api** - модуль общих DTO-объектов и интерфейсов

Предварительные требования:

    - Java 21 или выше
    - Maven 3.8+
    - PostgreSQL 15+
    - Docker (опционально)

Порядок запуска сервисов:

    - Discovery Server (порт: 8761)
    - Config Server (порт случайный)
    - Gateway Server (порт: 8080)
    - Бизнес-сервисы (core) (случайный порт)
    - Сервис-статистики (stats) (порт: 9090)

Экосистема Spring:

    - Spring Boot 3.3.0
    - Spring Cloud 2023.0.3
    - Spring Data JPA
    - Spring Web / Validation
    - Spring Actuator

Базы данных:

    - PostgreSQL 42.7.3
